# Video handoff: The First Conch pilot, 18 shots

For Vertex AI Media Studio (Veo, image to video). For each shot: upload the keyframe from `keyframes/` as the start image, paste the prompt and the negative prompt, and use the settings listed.

**Settings for every shot:** aspect ratio 16:9, 24 fps, resolution 1080p if offered, sound off (temp sound comes later), 2 takes per shot. The frames are 2.39:1; Veo will pad or crop to 16:9, so keep the action in the centre. Name each result `SHxxx_takeN.mp4` and put it in `art/motion/`.

**Hero shots** (SH010, SH050, SH070, SH090, SH130, SH150, SH170, SH180) are worth the top Veo model; use the fast or lite tier for the others first.
